## 📋 Описание проекта

Комплексная математическая модель хронического ревматоидного артрита, основанная на системе уравнений в частных производных с подвижной границей. Модель описывает:

- ⚡ **Воспалительные процессы** в синовиальной мембране
- 🦴 **Деградацию хрящевой ткани** 
- 💊 **Эффективность различных терапий** (биологические препараты, иммуносупрессоры)
- 📈 **Динамику клеточных популяций** и цитокинов
- 🔄 **Подвижную границу** между тканями

## 🧮 Математическая модель

### Общая структура

Система описывает три области:

1. **Ω⁻ (0 < x < L₁)**: Синовиальная жидкость
2. **Ω₀ (L₁ < x < h(t))**: Синовиальная мембрана
3. **Ω₊ (h(t) < x < L₂)**: Хрящевая ткань

где **h(t)** - подвижная граница, отражающая прогрессирование заболевания

### Примеры уравнений

**Th-17 клетки:**
```
∂T₁₇/∂t - δ₁₇ ∂²T₁₇/∂x² = λ_TI23 T₁₇ I₂₃/(K₂₃+I₂₃) + ... - d₁₇ T₁₇
```

**Макрофаги (с хемотаксисом):**
```
∂M/∂t - δ_M ∂²M/∂x² = A_M - ∂(M χ ∂P/∂x)/∂x + ... - d_M M
```

**Хондроциты (с переносом):**
```
∂C/∂t + ∂(VC)/∂x = A_C - d_CTα C T_α/(K_α+T_α) - d_C C
```

Полное описание всех уравнений см. в `RA_Model_Description.md`

## 🛠️ Технические детали

### Численные методы

- **Кранк-Николсон**: Для диффузионных уравнений (безусловно устойчив)
- **Upwind-схема**: Для конвективных членов (предотвращение осцилляций)
- **Явная схема**: Для реакционных членов (с проверкой устойчивости)

### Параметры дискретизации

- Временной шаг: Δt = 0.01 дня
- Пространственный шаг: Δx = 0.01 см
- Период моделирования: 100 дней
- Сетка: ~53 пространственных узла

### Требования к системе

- **RAM**: ≥4 ГБ (рекомендуется 8 ГБ)
- **CPU**: Многоядерный процессор (2+ ядра)
- **Диск**: ~500 МБ свободного места
- **ОС**: macOS, Linux, Windows
